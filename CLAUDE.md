# DevDisk Cleaner

A **Flutter macOS-only** app that scans for "developer junk" (Xcode/CoreSimulator, Gradle, Android SDK/NDK, JetBrains/Android Studio IDEs, Docker) and removes it **reversibly** (goes to the Trash via Finder, never `rm -rf`).

## Stack
Flutter (stable) · `flutter_bloc` (Cubit) · `get_it` (manual DI) · `equatable` · `flutter_localizations`/`gen_l10n` (i18n) · engine in pure Dart. macOS desktop only — aborts if `!Platform.isMacOS`.

## Architecture (Clean Architecture: `presentation → domain ← data`)
```
lib/
├── core/
│   ├── cleaner/clean_models.dart        # pure types (Safety, CleanAction, CleanupRule, ScanResult, DiskStats)
│   ├── cleaner/disk_cleaner_engine.dart # ENGINE (du/df/trash/keepLatest) + kRules + CLI main()
│   ├── process/process_runner.dart      # injectable process boundary (fakeable)
│   ├── util/byte_format.dart            # formatBytes()
│   └── di/injection.dart                # get_it wiring
├── domain/   # entities (re-export of the pure types) · repositories · usecases (ScanRules, CleanRules)
├── data/     # datasource (wraps the engine) · repository impl · rules/default_rules.dart (kRules)
├── presentation/
│   ├── cubit/   # CleanerCubit + CleanerState (single, equatable, enum CleanerPhase)
│   ├── theme/   # AppColors, AppText (design tokens)
│   ├── pages/cleaner_page.dart   # orchestrates idle→scanning→results→cleaning→done + modals
│   └── widgets/ # disk_gauge (CustomPainter), rule_row, risk_badge, danger_modal, empty_trash_modal, top_bar
├── l10n/app_localizations.dart   # GENERATED by gen_l10n (don't edit by hand)
└── main.dart  # BlocProvider above the MaterialApp; locale driven by the Cubit's AppLang
assets/language/app_*.arb   # source of the translations (PT/EN)
assets/fonts/*.ttf          # Space Grotesk + JetBrains Mono (variable, bundled)
docs/                       # disk_cleaner_spec.md (engineering) + README.md/DevDisk.dc.html (hi-fi design)
```

## Commands
```bash
flutter run -d macos                                   # dev
flutter build macos --debug                            # native build (validates entitlements)
flutter analyze && flutter test                        # lint + tests
flutter gen-l10n                                        # regenerate AppLocalizations after editing .arb
dart run lib/core/cleaner/disk_cleaner_engine.dart      # CLI: real scan (--apply cleans the safe ones)
```
