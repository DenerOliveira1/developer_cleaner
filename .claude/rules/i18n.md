# i18n (gen_l10n)

- **All UI text comes from the ARB** (`assets/language/app_*.arb`), accessed via `AppLocalizations.of(context)`. Don't hardcode strings in widgets.
- After editing `.arb`: run `flutter gen-l10n`. **Never edit `lib/l10n/app_localizations.dart`** (generated).
- Technical tokens (paths, docker commands, `ndkVersion`, `Macintosh HD`, versions) stay **identical** across all languages.
- Language toggle: the Cubit's `AppLang` drives `MaterialApp.locale`; `BlocProvider` sits **above** the `MaterialApp` to switch language without resetting state.
- **New language:** create `app_<code>.arb` → `flutter gen-l10n` → add a value to the `AppLang` enum + an `AppLang→Locale` mapping in `main.dart` + a button in the `TopBar`.
