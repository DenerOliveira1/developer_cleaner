# i18n (gen_l10n)

- **Todo texto de UI vem do ARB** (`assets/language/app_*.arb`), acessado via `AppLocalizations.of(context)`. Não hardcodar strings em widgets.
- Após editar `.arb`: rodar `flutter gen-l10n`. **Nunca editar `lib/l10n/app_localizations.dart`** (gerado).
- Tokens técnicos (paths, comandos docker, `ndkVersion`, `Macintosh HD`, versões) ficam **iguais** em todos os idiomas.
- Toggle de idioma: o `AppLang` do Cubit dirige `MaterialApp.locale`; `BlocProvider` fica **acima** do `MaterialApp` pra trocar idioma sem resetar estado.
- **Novo idioma:** criar `app_<código>.arb` → `flutter gen-l10n` → adicionar valor no enum `AppLang` + mapeamento `AppLang→Locale` no `main.dart` + botão no `TopBar`.
